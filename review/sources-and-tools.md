## Selection and sourcing workflow after first-four review

1. Establish each candidate's normal/fault voltage, current, power, pulse energy, SOA, temperature, precision/noise, working/common-mode isolation and lifecycle requirements before search. Separate design requirement from absolute-maximum rating.
2. For prototype purchases, run inventory `check` for the candidate BOM lines and record have/need/short/location, with ordered stock separately. For assembly, confirm JLC library stock, not merely the user's bench stock.
3. Use JLC search for suitable Basic parts first, then preferred Extended, then Extended only when electrically suitable. Verify exact C-numbers/MPNs, manufacturer datasheets, package/terminal functions, quantity plus attrition, prices and retrieval time. Availability cannot justify a safety/performance compromise.
4. Cross-check unusual parts/alternatives using Mouser `part <MPN> --exact` or documented keyword search; record manufacturer, datasheet, lifecycle, min/multiple and actual price currency. Independently verify manufacturer ratings and conditions; catalogue shorthand is insufficient.
5. Before upload run the JLC `bom` command against every BOM code. Archive evidence for stock, part identity and any approved alternatives; a substitution invalidates affected footprint, safety and calibration evidence.

## Placement, routing and checks

1. Start from the authoritative schematic/board revision and reviewed isolation/current/thermal/return-path plan. Keep `.kicad_pro` and `.kicad_dru` beside the `.kicad_pcb` with the same stem. Do not change the original board during routing.
2. Follow ktl-route's `rules import-dru` workflow for the actually selected JLC process profile. Complete voltage domains from approved boundary stresses, not net names. Review proposed `classify` roles for aggressor/victim, Kelvin, guarded and differential nets. Incorporate stricter project rules into the router rules before routing.
3. Run `rules check`. Resolve unmapped nets/conflicts and `IMPOSSIBLE_RULE` footprint/placement problems; no clearance weakening or bypass just to obtain a route. Solder-mask and manufacturing settings must match KiCad.
4. Run only the installed ktl-route, under `nice`, one router at a time after checking machine load; use the skill's documented run/report/time-limit options. No Freerouting or other silent substitute; do not modify the router's source/development tree.
5. Inspect `summary.md`, failed-connection reasons, actual clearance tables, DRC delta, warnings and rendered board. Exit 0 can still leave unrouted connections. Exit 2/new DRC errors on router copper mean output is not acceptable: preserve/report evidence. Placement failures call for placement changes, not repeated longer runs.
6. Deliver routed PCB/project/rules and report together. Require complete intended connectivity, relevant ERC/full DRC and review of all exceptions; manual isolation, current/thermal, grounding/return, shielding and sensitive analog review still required. Do not equate geometric DRC with electrical safety or measurement validation.

## Exact JLC assembly and fabrication deliverables

1. Audit the authoritative routed board/revision, actual assembly parts, electrical values/ratings and verified MPN/LCSC identity against manufacturer/supplier evidence.
2. Fetch/cache **exact LCSC code → supplier package UUID → numbered physical terminal** data with URLs, retrieval time and hashes. Verify coordinate/loader convention; do not assume generic rotation tables or copy another project's offsets.
