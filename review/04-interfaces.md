# Board-to-board interface-control document

Revision 0.9 — 7 November 2026 — G4 logical draft; G1-06 microphonics, G1-07 partition, G2-06 cooling, G2-07 internal-bank preference, G2-09 comparison modes, G2-10 shared power allocation and G2-11 two-section capacity included. **Not a released connector specification.**

No pinout is assigned before G3 review. Every “TBD” below blocks release of the affected interface, not the preparation of this draft.

## Modules and reference domains

G1-07 confirms that these logical modules impose **no one-PCB-per-module requirement**. Physical partition remains Provisional until G3/G4 review. Splitting or combining boards must preserve agreed functional coverage, adapter modularity, safety independence and reviewed isolation, return-current/noise and thermal constraints.

| Logical module | Responsibilities | Domain / return rule |
|---|---|---|
| M0 input/safety power | Mains entry, protective earth, isolation and auxiliary distribution | P primary and C chassis; approved crossings only |
| M1 control and safety | PC API, local commands, state machine, independent permits, logging | L control; safety independence from application controller must be demonstrated |
| M2 heater | Floating AC/DC generation, Kelvin voltage/current, reference control | H floating; H− is not chassis or cathode by default |
| M3 electrode power | Anode/screen/grid regulation, source/sink paths, local limits/discharge | T valve domain; per-rail returns documented, not inferred from net name GND |
| M4 measurement/audio/diagnostics | V/I acquisition, low-energy checks, stimulus, analyzer, calibration switching | Quiet analog area in T or isolated front end; ADC location Open |
| M5 matrix/socket adapter | Power/sense routing, identity, contact verification, guarded access | Mixed T/H; logic crossing to L must be isolated as required |
| M6 resistive load bank | Resistor bank, sense, thermal/discharge/guard functions | X load-power area, normally related to T; internal placement preferred and Provisional under G2-07; reference/isolation relation Open |
| M7 calibration module | External reference identity and standards | K accessible domain with reviewed protected crossing |

The M1 safety functions may be a separate circuit/board from the application controller. The table groups function, not safety independence. The full-load/PIV rectifier fixtures are separate systems; no connector in this ICD authorizes their connection to the main-unit outputs.

G2-07 prefers M6 inside the main enclosure, with final placement Provisional. The logical I019/I020 interfaces still need power/sense, cooling, guard and discharge coverage; no external load connector is mandated. X identifies load-power circuitry for review, not proof of a separate galvanic isolation boundary. Keep resistor heat and power returns separated from precision paths; define actual delivery ports and returns under D004/G4.

G2-09 requires concurrent pair/section operation as the preferred comparison mode and a selectable sequential mode. M1/M3/M4/M5 must distinguish each logical test path in commands, reservations, results and faults. I006 and I010–I015 represent interface families for the two logical section paths agreed under G2-11; their physical multiplicity and electrical sharing remain Open; the single row per rail does not limit the product to one active device or duplicate its power rating per device. I007–I009 must identify every energized heater and permitted shared reference. Define channel/result identity, acquisition timing/skew, crosstalk, cross-channel fault propagation and mode transitions before G4 release. No extra connector, converter, ADC or PCB count is selected. All paths share one combined output ceiling. G2-10 confirms 90 W anode, 15 W screen and 60 W heater as shared main-unit power capacities with flexible allocations; electrode numbers remain Provisional. I006 must carry enough path/allocation identity to enforce the shared totals and per-path limits. Current sharing and individual channel ratings remain Open; the current figures in I007/I010/I011 are existing targets, not new duplicated-per-channel or approved aggregate current ratings. G2-11 fixes concurrent capacity at two separately identified section paths; it does not fix socket/connector/regulator/ADC count. G2-12 requires independent DC bias requests for the two paths on I006 and I012. The linked command assigns the same setpoint to both paths. Report measured grid-to-cathode voltage and bias validity separately for each section.

## Grounding, shielding and return-current plan for review

1. Reserve C for protective chassis/shields under the selected safety class. Do not route normal heater, plate or screen current through PE. T-to-C signal bond, if any, is a controlled design decision with a defined location and impedance, not an accidental connection through the PC or scope.
2. Keep high di/dt converter loops local to their power modules. Route each high-current output with its intended return; separate matrix actuator/relay currents from electrode sensing. Add all intended DC/DC and isolation capacitances to common-mode noise analysis.
3. Take voltage sense differentially at the defined terminal boundary; use separate Kelvin current-sense connections. Keep heater current and screen return away from grid-current/leakage paths. DHT reference-current routing needs an explicit Kirchhoff-current model before selecting sense locations.
4. Place measurement source/analyzer and reference paths away from switching nodes, transformer fields and hot load-bank components. Quiet ground areas must maintain continuous return paths for their own signals; arbitrary split planes can create return loops. Guarding and shield termination require leakage/CMRR experiments, including contamination and humidity.
5. Treat cable shields and connector shells as explicit circuit connections in the ICD. Review where displacement current returns and whether both-end shielding creates loops; there is no blanket “ground every shield at one end” rule.
6. Preserve isolation in test equipment, service tools and external calibration modules. Review every bench connection before powering floating prototypes.

## Review contract

**Established:** functional boundaries from B§5 and required interface fields from B§6. **Open:** physical realization and all TBD limits; candidate domain partition and board count are unapproved. **Assumptions:** accessible control/calibration domain separated from guarded T/H; final product class and T/chassis relationship unresolved.

**Verification:** walk every cross-board wire against this table and the safety diagram; inject missing, shorted, swapped and partially powered interfaces; check power and return accounting; then review schematic/ERC and connector pin/terminal correspondence. Do not suppress failure behavior behind a generic bus specification.

**Pass G4 only when:** G1–G3 passed, board partition accepted, every implemented link has signed-off levels/references/common-mode bounds/power/timing/defaults, physical connectors and keying are safely specified, all relevant decisions closed, and schematic/prototype owners accept the contract. This draft intentionally does not meet that release condition yet.
